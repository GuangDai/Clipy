## 6. Apple API 官方文档核实记录（本轮新增结论的全部依据）

| API | 核实结论 | 文档 |
|---|---|---|
| `AppIntent.supportedModes: IntentModes` | macOS 26.0+ 官方 API；`.background` = "run the action entirely in the background"。X.7 六个 intent 的用法正确（且遵守 roadmap"不用 macOS 27 的 `allowedExecutionTargets`"约束） | [supportedModes](https://developer.apple.com/documentation/appintents/appintent/supportedmodes) |
| `IntentModes` | OptionSet（macOS 26+）；`.background`/`.foreground(_:)` 两类；运行期经 `systemContext.currentMode` 查询 | [IntentModes](https://developer.apple.com/documentation/appintents/intentmodes) |

| `NSWindow.CollectionBehavior.canJoinAllSpaces` | "The window can appear in all spaces."（"every-space" 的正确拼写） | 同上 |
| `NSWindow.CollectionBehavior.fullScreenAuxiliary` / `.stationary` / `.auxiliary` | "displays on the same space as the full screen window" / "Mission Control doesn't affect the window" / "auxiliary for both Stage Manager and full screen" | 同上 |
| `SMAppService` | macOS 13+；`mainApp`、`register()/unregister()`、`status`、`SMAppService.Status` 枚举、**`openSystemSettingsLoginItems()` 存在**——Card 10C 的缺口是产品未用，不是 API 不存在 | [SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice) |
