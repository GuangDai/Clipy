# Clipy

macOS 26 及以上、Apple Silicon 上的本地剪贴板历史应用。

按 `⇧⌘C` 打开历史面板，输入搜索，方向键选择，回车复制并返回原应用。也可以从菜单栏图标打开面板，或在设置的历史工作区浏览、预览和批量管理。

- 保留一次复制中的多个系统剪贴板项目、表示形式及原始字节；重复复制合并次数和时间。
- 支持精确、模糊、正则和布尔表达式搜索，类型、来源、时间与置顶筛选。
- 支持置顶和排序、删除、保留策略、不可变内容修订、拖出及原始表示导出。
- 支持文本、图片、离线 HTML / RTF / RTFD 和静态 PDF 预览。本地文件需用户明确加载。
- 默认保留最近 200 条未置顶记录；数量限制可关闭，单项资源限制和其他保留策略独立生效。
- 维护页面可导出一致性备份；自动化页面提供内置工作流、独立授权和随应用打包的 `clipyctl`。

历史存入本机 SQLite 和不可变 UUID 内容文件。旧布局不会被自动读取、迁移或删除。备份包含原始内容和修订，未加密，现有目标目录不会被覆盖。

完整文档见 [docs/README.md](docs/README.md)。开发入口是 [架构](docs/architecture.md)、[存储](docs/storage.md)、[搜索](docs/search.md) 与 [CI 验证](docs/testing.md)；命令行使用见 [自动化](docs/automation.md)。

SwiftPM 管理库，XcodeGen 管理应用及宿主测试。验证只使用 macOS CI，不运行本地 Swift；运行状态通过 `gh run watch --exit-status` 等待。
